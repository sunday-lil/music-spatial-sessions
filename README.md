# Music — Spatial Sessions

一个仿 Apple Music「正在播放」体验的沉浸式音乐可视化概念。
不是静态海报：页面里有一支用 Web Audio 实时合成的四首曲目，频谱、波形、光环和背景极光都跟着真实音频呼吸。

## 打开方式

直接双击 `index.html` 即可。

- 无需安装、无需构建、无需联网。
- 没有外部图片、字体或音频文件；封面由 Canvas 现场绘制，音乐由 Web Audio 现场合成。
- 建议使用最新版 Chrome / Edge，并戴上耳机。
- 浏览器要求用户手势后才能播放声音：点击白色播放按钮即可开始。

## 设计说明

想做出 Apple 那种「贵」的感觉，靠的不是堆特效，而是克制：

- **一个视觉中心**：蚀日封面上只允许出现一轮光、几条轨道和极小的唱片文案。
- **数据驱动的光**：背景极光、封面周围的频谱光环、底部波形，三层动效来自同一个 AnalyserNode；低频、中频、高频分别控制不同的视觉层。
- **留白与层级**：大标题使用紧字距和极短行高；辅助信息压到 9–11px 并降低不透明度；所有胶囊、卡片、抽屉使用同一套圆角与毛玻璃语言。
- **材质**：SVG 噪点、Canvas 颗粒、内阴影、顶部高光、柔和投影，让界面像一块有厚度的黑色玻璃，而不是纯色网页。
- **有节制的动效**：封面 10 秒一次漂浮，极光以 30fps 缓慢漂移，唱片光环只以 1px 细线回应频率；没有跳动的彩色柱状图。
- **排版**：英文标题使用 SF Pro / Segoe UI Variable 系统字体栈，中文使用苹方 / 微软雅黑 UI；全部本地字体，保证离线。

## 技术细节

- **音频图**：Pad → 低通 → 声场 → 干声总线 + 混响送出；琶音额外送入带反馈的延迟。总线经过压缩器、AnalyserNode、音量控制后输出。
- **编曲**：每个小节提前约 2.3 秒排程；Pad、Bass、Arp、Kick、Hat、Brush、Shimmer 按曲子进度和确定性随机数决定进入与休止。
- **可视化**：
  - 全屏极光：6 个径向渐变光团，按频段能量缩放，低分辨率 Canvas 放大以得到柔和的胶片感。
  - 封面光环：132 根镜像频谱细线 + 两条极细轨道线，随时间和播放状态缓慢旋转。
  - 波形：时域数据经过自动增益和平滑后，绘制成对称的填充波形；暂停时退化为缓慢的正弦呼吸。
- **封面**：900×900 Canvas 绘制渐变、星点、轨道、日食、地平线、颗粒和暗角；四首曲子通过配色与日食偏移形成同一视觉系列。
- **可访问性**：所有按钮有中文 `aria-label`；播放状态、静音、随机、循环使用 `aria-pressed`；队列打开时焦点移入抽屉，背景设为 `inert`；尊重 `prefers-reduced-motion`。

## 说明

- 曲目、艺人和歌词均为虚构，仅为视觉与交互演示。
- 音频是实时合成的环境音乐，不是唱片录音；不同浏览器的合成器音色会有细微差异。
- 这是一个独立的视觉与交互练习，与 Apple Inc. 无关联。
